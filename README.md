# 宝可梦 · 狩猎对决（Godot 4 Demo）

参考 [PokéHunt](https://pkhunt.online/en/play) 的玩法，用 Godot 4.7 做的一款可玩的卡牌化宝可梦收集 / 放置狩猎 / 回合制对战游戏。

## 运行

1. 用 Godot 4.7（4.3+ 应该都可以）导入本目录的 `project.godot`。
2. 按 F5 运行。首次进入选择初始宝可梦（品质随机，至少稀有，可重抽 3 次）。

命令行冒烟测试（使用独立存档，不影响正式进度）：

```powershell
Godot_v4.7.2-stable_win64_console.exe --headless --path . -- --smoke          # 逻辑 + 界面
Godot_v4.7.2-stable_win64_console.exe --path . -- --smoke --shots             # 额外把每个界面截图到 screenshots/
```

## 玩法与机制

| 系统 | 说明 |
| --- | --- |
| 卡牌 | 每只宝可梦都是一张卡：外层**品质框**（6 档：普通 / 优良 / 稀有 / 史诗 / 传说 / 神话，加闪光），内层**属性框**（18 种属性配色），中间立绘槽，底部显示能力值 |
| 个体 | 个体值 IV（每项 0~31）、25 种性格（±10%）、品质加成（最高 +30%），闪光再 +10%。同一物种的两只永远不同 |
| 地图 | 11 个地区，按等级递进；击败当前地区的馆主解锁下一个 |
| 自动狩猎 | 选择地区后每 4 秒自动结算一场战斗，获得经验和金币；可设置自动捕捉（新种类 / 闪光 / 指定品质以上）。离线最多累积 12 小时收益 |
| 野外遭遇 | 手动回合制战斗：技能、背包（精灵球 / 药品）、换宝可梦、逃跑；有自动战斗和 2 倍速 |
| 精灵球 | 精灵球 ×1 / 超级球 ×1.5 / 高级球 ×2 / 大师球必中。HP 越低、陷入异常状态越容易抓，品质越高越难抓 |
| 练级 | 经验曲线 Lv³；首发拿全部经验，其余队员拿一半（学习装置）。升级自动学技能，到等级自动进化；神奇糖果直接 +1 级 |
| 技能 | 89 个技能：物理 / 特殊 / 变化，属性克制（18×18）、本系加成、要害、命中、能力等级 ±6、灼伤 / 中毒 / 麻痹 / 睡眠 / 冰冻、吸血、反伤、先制。详情页可自由装备 4 个已领悟的技能 |
| 挑战 | 道馆馆主（11 位，首胜给徽章和道具）、对战塔（无尽层数，每 5 / 10 层里程碑奖励）、传说降临（5 只传说宝可梦，可捕捉） |
| 其他 | 队伍 6 只 + 仓库、背包、商店、图鉴、放生、改昵称、自动存档（30 秒 + 退出时） |

## 卡牌编辑器（游戏内）

左侧导航「卡牌编辑器」：选择物种，修改名称、属性、种族值、捕获率、进化目标 / 等级、是否传说、自定义立绘路径，右侧实时预览不同品质框和闪光效果。

- 「保存修改」写入 `user://mods/species_overrides.json`，覆盖默认数据，所有该物种个体立即按新数值计算。
- 「写回 data/species.json」仅在编辑器中运行时可用，会把修改合并回项目文件。

## 数据文件（直接改 JSON 即可调数值）

| 文件 | 内容 |
| --- | --- |
| `data/species.json` | 物种：名称、图鉴号、属性、种族值、捕获率、进化、技能表（`learnset_ref` 可复用同系列技能表） |
| `data/moves.json` | 技能：属性、分类、威力、命中、先制、要害、附加效果 |
| `data/items.json` | 道具：精灵球倍率、药品回复量、价格 |
| `data/world.json` | 地区（等级范围、地图坐标、野生出现权重、馆主队伍与奖励）和传说宝可梦 |

## 美术替换

把图片放到约定路径即自动生效，缺图时显示程序绘制的占位图。完整的路径规范和 gpt-image 提示词见 [docs/art_prompts.md](docs/art_prompts.md)。

```text
assets/pokemon/<物种ID>.png            立绘（朝左，透明背景）
assets/pokemon/<物种ID>_shiny.png      闪光立绘（可选）
assets/ui/frames/rarity_<品质ID>.png   品质框
assets/ui/frames/type_<属性ID>.png     属性底框
assets/ui/world_map.png                世界地图
assets/ui/battle_bg[_<地区ID>].png     战斗背景
assets/items/<道具ID>.png              道具图标
```

## 代码结构

```text
scripts/
  autoload/db.gd          静态数据（JSON 加载、属性克制、品质、性格、物种覆盖）
  autoload/game.gd        存档、队伍/背包、敌人生成、战斗结算、自动狩猎、离线收益
  core/monster.gd         宝可梦个体（能力值计算、经验、技能学习、进化、序列化）
  core/battle_engine.gd   纯逻辑回合制战斗引擎（事件流 + AI + 捕获公式 + 瞬时模拟）
  ui/main.gd              主框架（顶栏 / 导航 / 弹窗 / 提示）
  ui/battle_screen.gd     战斗界面与动画
  ui/monster_card.gd      卡牌组件（品质框 + 属性框 + 立绘）
  ui/screens/*.gd         地图、队伍、挑战、背包、商店、图鉴、卡牌编辑器
tests/smoke.gd            冒烟测试
```
